## 🏗️ Projeto principal

### ByteShift Atlas
> Plataforma SaaS multi-tenant para operações de SOC com integração multi-SIEM, automação SOAR e detection engineering baseado em MITRE ATT&CK.

**Tecnologias:** Node.js · TypeScript · Fastify · Next.js · PostgreSQL · TimescaleDB · Wazuh · Supabase

- Integração com Wazuh, Splunk, Microsoft Sentinel e outros SIEMs
- Motor de detecção customizado com sliding window counters e alertas via webhook
- Arquitetura multi-tenant com mTLS para autenticação de agentes
- Pipeline de automação SOAR para resposta a incidentes
