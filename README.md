### About

Cybersecurity professional with hands-on experience across offensive and defensive security. Founder of **ByteShift Atlas**, a multi-tenant SaaS SOC platform consolidating SIEM, SOAR, CSPM, CWPP, CIEM and DSPM into a unified SecOps solution with MITRE ATT&CK-based detection engineering.

Previously worked as **Endpoint Security Analyst at Santander Brasil** (via Motivus), operating CrowdStrike Falcon, Netskope, Cisco Umbrella, Trellix, Qualys and Splunk in a large-scale financial environment.

Certified **CRTA (Certified Red Team Analyst)** — current focus is offensive security: red team operations, Active Directory attacks, web exploitation, vulnerability research and building tools that bridge the gap between attack and defense.
